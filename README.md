# PartyMaker API

Веб-сервис для генерации QR-приглашений в комнаты мероприятий. API позволяет создавать приглашения с QR-кодами для быстрого доступа к комнатам событий.

Возможности

- Генерация уникальных приглашений для комнат мероприятий
- Создание QR-кодов со ссылками для присоединения
- Автоматическое формирование ссылок с параметрами комнаты
- Хранение истории созданных приглашений
- Swagger документация API

Технологии

- **.NET 8** / **.NET Core**
- **ASP.NET Core Web API**
- **QRCoder** - библиотека для генерации QR-кодов
- **Swagger/OpenAPI** - документация API

Установка и запуск

Предварительные требования

- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- IDE (рекомендуется Visual Studio 2022 / VS Code / Rider)

### Локальный запуск

1. Клонируйте репозиторий:

git clone https://github.com/yourusername/PartyMaker.API.git
cd PartyMaker.API

Восстановите зависимости:
bash
dotnet restore
Запустите приложение:
bash
dotnet run
    Откройте браузер и перейдите по адресу:
text
http://localhost:5000
Swagger UI будет доступен автоматически
